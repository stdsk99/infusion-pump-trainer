# Infusion Pump Repair Trainer

สื่อฝึกซ่อมเครื่องควบคุมการให้สารละลาย (volumetric infusion pump) แบบ interactive สำหรับวิชาเครื่องมือแพทย์

## โมดูล

1. หลักการทำงาน – ภาพตัดภายในและ block diagram ที่แตะดูได้
2. รหัส Alarm – 15 alarm พร้อมสาเหตุและลำดับการตรวจ
3. จำลองการซ่อม – โหมดเรียนรู้ (แอนิเมชันทีละขั้น) และโหมดสอบ (ตรวจอิสระ มีคะแนน) 8 เคส
4. การทดสอบหลังซ่อม / PM – flow, occlusion, air, electrical safety (IEC 62353), functional พร้อมเครื่องคำนวณ โจทย์ฝึก และแบบบันทึกผล
5. ลำดับขั้นตอน – แตะเรียงขั้นตอนงาน 3 งาน
6. แบบทดสอบ – สุ่ม 20 ข้อจากคลัง 30 ข้อ

## โครงสร้างไฟล์

```
index.html            โครงหน้าเว็บ + ภาพ SVG โมดูล 1
css/style.css         หน้าตาเว็บ + responsive
js/app.js             เมนู, โมดูล 1–2
js/learn.js           โมดูล 3 โหมดเรียนรู้ (ภาพเครื่องเคลื่อนไหว)
js/sim.js             โมดูล 3 โหมดสอบ + หน้าเลือกโหมด
js/pm.js              โมดูล 4
js/order.js           โมดูล 5
js/quiz.js            โมดูล 6
js/score.js           ระบบคะแนน / หน้า "ผลของฉัน"
data/config.js        ตั้งค่า URL ส่งคะแนนเข้า Google Sheets
data/parts.js         เนื้อหาชิ้นส่วน (โมดูล 1)
data/alarms.js        เนื้อหา alarm (โมดูล 2)
data/learn.js         ฉากโหมดเรียนรู้ (โมดูล 3)
data/cases.js         เคสโหมดสอบ (โมดูล 3)
data/pm.js            เนื้อหาการทดสอบ (โมดูล 4)
data/order.js         ขั้นตอนงาน (โมดูล 5)
data/quiz.js          คลังข้อสอบ (โมดูล 6)
apps-script/          โค้ดและวิธีตั้งค่า Google Sheets รับคะแนน
```

แก้เนื้อหาได้ในโฟลเดอร์ `data/` โดยไม่ต้องแตะโค้ด เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที

## ขึ้น GitHub Pages

1. สร้าง repo ใหม่ แล้วอัปโหลดไฟล์ทั้งหมดโดยคงโครงสร้างโฟลเดอร์ไว้
2. ไปที่ Settings → Pages → Source เลือก `Deploy from a branch`, branch `main`, โฟลเดอร์ `/ (root)`
3. รอประมาณ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## ระบบส่งคะแนน

ดูวิธีตั้งค่าใน `apps-script/README.md` ถ้าไม่ตั้งค่า คะแนนจะเก็บในเบราว์เซอร์ของนักศึกษา และนักศึกษากด "คัดลอกผลทั้งหมด" ในหน้า "ผลของฉัน" เพื่อส่งให้อาจารย์ได้

## หมายเหตุ

เครื่องในแอปเป็นเครื่องจำลองทั่วไป เนื้อหาและภาพทั้งหมดจัดทำขึ้นใหม่เพื่อการศึกษา ไม่ได้คัดลอกจากคู่มือของผู้ผลิตรายใด
